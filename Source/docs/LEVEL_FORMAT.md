# Level format
Levels are plain JSON (`src/js/levels-data.js`, generated by `scripts/generate-levels.mjs`).

```json
{ "id":"p2-3", "pack":2, "k":3, "seed":123456, "n":6, "exit":"R",
  "walls":[[1,4]],
  "veh":[["sedan",0,2,"h",0,0], ["bus_city",3,0,"v",1,3]],
  "min":11, "d":2, "stars":[13,20], "lim":23 }
```
- `n` – board is n×n. `exit` – side where the hero leaves: `R`, `L`, `T` or `B`.
- `veh` rows: `[typeId, x, y, orientation('h'|'v'), reversedFacing(0|1), colourIndex]`. `(x,y)` is the top-left cell. **Row 0 is always the hero.** A vehicle of type length `len` and width `wid` covers `len×wid` cells when `h` and `wid×len` when `v`; it slides only along its orientation.
- `walls` – immovable barriers. `min` – exact minimum number of moves (one move = slide one vehicle any distance), proven by BFS. `d` – difficulty tier 0..5 (Beginner, Easy, Medium, Hard, Expert, Master) derived from `min`. `stars` – move thresholds for 3 and 2 stars. `lim` (optional) – move limit.
- The hero wins when its axis position equals `n - len` (exit R/B) or `0` (exit L/T).
- `seed` – seed of the generator run that produced the level (reproducible with the same code and parameters).

# Save format (localStorage key `rahbaz.save`, version 1)
`{v, lang, coins, xp, skin, skins[], set{sfx,music,anim}, lv{id:{s,b,t,n}}, ach{id:ts}, last, daily{date,done,streak,lastDone}, endless{best}, timeBest, minDone{}, st{...stats}}`.
`store.js#migrate` fills defaults for fields added in later versions. A corrupt save is copied to `rahbaz.save.bad` and replaced by a fresh one.
